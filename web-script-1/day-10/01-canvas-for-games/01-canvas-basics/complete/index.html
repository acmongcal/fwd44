Demo 1: Canvas Basics

This demo introduces the canvas element. JavaScript draws a rectangle and moves it around the screen.

Teaching Notes

  • The canvas is placed in HTML, but the rectangle is drawn by JavaScript.
  • The grid is drawn with loops that repeat drawing commands at regular intervals.
  • The top-left corner is coordinate (0, 0).
  • Moving right means x increases. Moving down means y increases.
